# Educational Games

Free, classroom-ready games for teachers. Each game is a single file you can download and open in a web browser. No installs, no accounts, no internet required once downloaded.

## Games

| Game | Description |
|------|-------------|
| [Jeopardy](games/jeopardy/) | Team quiz game. Upload a CSV of clues, make teams, and play. Works great shared in Zoom, Adobe Connect, or Google Meet. |

## How to download

**One game:** open the game's folder, click the `.html` file, then click the **Download raw file** button (the down-arrow icon).

**Everything:** click the green **Code** button at the top of this page, then **Download ZIP**, and unzip it.

Each game folder has its own README with step-by-step instructions.

## Repository layout

```
games/
  _template/     starting point for adding a new game
  jeopardy/      Jeopardy-style review game
```

## Contributing

To add a game, copy `games/_template/` to `games/your-game-name/` and fill in its README.
