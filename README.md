# Educational Games from LogosTeach

Welcome! This is a free collection of classroom games made by **LogosTeach** for teachers, parents, and homeschool families. You can use them in a classroom, at the kitchen table, or in an online class (Zoom, Adobe Connect, Google Meet).

- **It's free.** The games use the **MIT License**. In plain words: you may use, copy, change, and share them for free. Just keep the license file with them. (See [LICENSE](LICENSE).)
- **No installing.** Each game is a web page file that opens in the web browser you already use (Chrome, Edge, or Safari).
- **No internet needed to play** once you've downloaded a game.

## What is GitHub?

You're reading this on **GitHub**. GitHub is a website where people store and share files and projects, a bit like a public Google Drive or Dropbox folder.

- You can ignore most of the buttons on this page. You only need the few steps below.

## How to download a game to your computer

Pick **Option A** if you just want one game. Pick **Option B** if you want everything (games, sample question files, and pictures).

### Option A: download just one file

1. Go to the game's folder. For Jeepody, click [games/jeopardy](games/jeopardy).
2. Click the game file. For Jeepody, it's **jeopardy-app.html**.
   (The file and folder names still say "jeopardy". That is normal, and it is the right file.)
3. A page opens showing the file. Near the top right, click the **Download raw file** button. It looks like a small arrow pointing down into a tray.
4. The file is saved to your computer, usually in your **Downloads** folder.

You can download the sample question file the same way: open the **samples** folder, click **[sample-jeopardy-cross-curricular.csv](games/jeopardy/samples/sample-jeopardy-cross-curricular.csv)** (Math, English, Biology, Chemistry, and History questions), and click **Download raw file**. Edit it to make your own game.

### Option B: download everything (ZIP file)

1. Go to the main page of this repository: https://github.com/logosteach/educational-games
2. Click the green **Code** button near the top.
3. Click **Download ZIP**.
4. A file named **educational-games-main.zip** is saved, usually in your **Downloads** folder.

A **ZIP file** is a folder that has been squeezed into one file so it downloads faster. You need to "unzip" it (open it up) before using it:

- **Windows:** open your **Downloads** folder, **right-click** the ZIP file, choose **Extract All…**, then click **Extract**. A normal folder appears next to the ZIP file.
- **Mac:** open your **Downloads** folder and **double-click** the ZIP file. A normal folder appears next to it.

Inside the new folder, open **games**, then **jeopardy**, to find **jeopardy-app.html**.

Tip: move the unzipped folder somewhere easy to find, like your Desktop or Documents.

### Where did my download go?

- Most browsers save to your **Downloads** folder.
- **Windows:** open **File Explorer** (the yellow folder icon on the taskbar) and click **Downloads** on the left.
- **Mac:** open **Finder** and click **Downloads** on the left.
- In your browser, you can also press **Ctrl + J** (Windows) or **Option + Command + L** (Mac, in Chrome) / the download arrow in the toolbar to see recent downloads.

## How to open a game

Game files end in **.html**. That's the same kind of file as a web page, so your web browser opens it.

1. Find the file (for example **jeopardy-app.html**) in your Downloads folder or the unzipped folder.
2. **Double-click** it. It opens in your web browser.
3. If it opens in the wrong program, **right-click** the file, choose **Open with**, and pick **Google Chrome**, **Microsoft Edge**, or **Safari**.

Chrome or Edge work best. The game opens in a browser tab, but it runs from your own computer.

## Need help?

- **I clicked the file and saw lots of code text instead of a game.** You're viewing the file on GitHub, not your computer. Click **Download raw file**, then open the downloaded file. Or use the play-online link above.
- **The file opened in Notepad, Word, or another program.** Right-click the file, choose **Open with**, and pick Chrome, Edge, or Safari.
- **I can't find the green Code button.** Make sure you're on the main repository page: https://github.com/logosteach/educational-games
- **The game is inside a ZIP and won't work.** Unzip it first (see Option B), then open the file from the new, unzipped folder.
- **My computer warns me about the download.** These files are plain web pages with no programs to install. You can choose **Keep** in your browser.
- **There's no sound.** Click anywhere on the game page once, and check that your computer's volume is up.
- **Still stuck?** Ask a tech-savvy friend to look at this page with you, or search the web for your exact question (for example, "how to unzip a file on Windows").
